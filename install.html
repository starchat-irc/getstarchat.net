Install

Just use it

Open the web demo. It connects to #starchat on ST-City. Under "Advanced settings" in the login dialog you can pick another network. As with any IRC client, the network sees your IP address.

Desktop app

For Windows, Linux and macOS on the releases page. The app updates itself. The installers are not signed yet, so Windows and macOS warn on the first start.

Android

The app is in a closed test on Google Play, and testers are welcome:

  1. Join the Google group starchat-irc with your Google account.
  2. Open the test page on Google Play and tap "Become a tester". It works as soon as Google has approved the first version.
  3. Install StarChat from Google Play.

Feedback is welcome in #starchat on ST-City or on GitHub. Without Google Play you can install the development build as APK.

Host the web client yourself

The web client is a static page, any web host works.

  1. Download starchat-web-<version>.zip from the releases page.
  2. Unpack it and set your network in starchat-web/config.json:
{
    "primaryServer": "irc.example.org",
    "defaultChannel": "#lobby"
}
  1. Upload the folder to your web host.

All settings are under Hosting the web client.

Embed it in your site

npm install starchat, then:

import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap-icons/font/bootstrap-icons.min.css';
import 'starchat/theme.css';
import { mountChat } from 'starchat';

mountChat('#chat', {
    primaryServer: 'irc.example.org',
    defaultChannel: '#lobby',
});

See mountChat() options and Embedding with login.

For network operators

The desktop app works with any network over TCP. For the web client your server needs:

  1. WebSocket over TLS (wss://). Ergo, UnrealIRCd 6 and InspIRCd (m_websocket) support it.
  2. Allowed origins, if your server checks them (Ergo: server.websockets.allowed-origins). Add the pages your users chat from, for the demo https://getstarchat.net.

Optional: a discovery file at https://<your-domain>/.well-known/starchat.json, served with Access-Control-Allow-Origin: *, so users only need to type your domain:

{
    "schemaVersion": 1,
    "name": "Example Network",
    "websocketUrl": "wss://irc.example.org/webirc"
}

To appear in the network list of every StarChat, add your network to servers/servers.json by pull request (format).
