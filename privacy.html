6. Push-Benachrichtigungen der Android-App

Bist du in einem Netzwerk angemeldet, das Web Push unterstützt, und erlaubst du Benachrichtigungen, meldet sich die App für Push an. Dafür erzeugt die App auf deinem Gerät eigene Schlüssel und erhält von Firebase Cloud Messaging (FCM) ein Geräte-Token.

Push-Gateway: Die App schickt das FCM-Token an unser Push-Gateway push.getstarchat.net. Das Gateway prüft bei FCM, ob das Token zur StarChat-App gehört, und antwortet mit einer Push-Adresse, die das Token verschlüsselt enthält. Diese Adresse und die öffentlichen Schlüssel deines Geräts gibt die App an das IRC-Netzwerk weiter. Das Netzwerk schickt Benachrichtigungen an das Gateway, das sie an FCM weiterreicht.

Das Gateway speichert keine Tokens, keine Push-Adressen und keine Inhalte und protokolliert keine IP-Adressen. Zur Begrenzung von Missbrauch hält es die IP-Adresse bei der Anmeldung bis zu zehn Minuten im Arbeitsspeicher. Es läuft auf einem gemieteten Server; der Hosting-Anbieter verarbeitet die Daten in unserem Auftrag (Art. 28 DSGVO).

Inhalt: Absender und Text einer Benachrichtigung verschlüsselt das IRC-Netzwerk mit den Schlüsseln deines Geräts (RFC 8291). Erst die App auf deinem Gerät entschlüsselt sie. Weder das Gateway noch Google können den Inhalt lesen.

Firebase Cloud Messaging: Die Zustellung übernimmt FCM der Google Ireland Ltd., Gordon House, Barrow Street, Dublin 4, Irland. Dabei ist eine Übermittlung an Google LLC in den USA möglich. Google ist unter dem EU-US Data Privacy Framework zertifiziert. Von Firebase nutzen wir nur die Nachrichtenzustellung, keine Analyse- oder Werbefunktionen. Siehe die Datenschutzhinweise von Firebase.

Rechtsgrundlage ist deine Einwilligung (Art. 6 Abs. 1 lit. a DSGVO), die du über die Benachrichtigungs-Abfrage deines Geräts erteilst und dort jederzeit widerrufen kannst. Löschst du die App, wird das Token ungültig und das Netzwerk entfernt die Anmeldung beim nächsten Versuch.

2. Overview

This policy covers the website getstarchat.net (with documentation and demo), the StarChat apps for the web, the desktop (Windows, Linux, macOS) and Android, and the push gateway push.getstarchat.net.

StarChat runs no chat server of its own. The apps connect directly to the IRC network you choose. What you write there, who you are there and which features the network offers (for example accounts, uploads, voice chat) is processed only by the operator of that network, under its own privacy policy.

We use no tracking, no analytics and no advertising, neither on the website nor in the apps.

3. Website (GitHub Pages)

The website is served by GitHub Pages, a service of GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Netherlands (parent company GitHub, Inc., USA). GitHub processes data needed to deliver the pages, in particular your IP address, and keeps it in logs for the security of the service. It may be transferred to the USA. GitHub is certified under the EU-US Data Privacy Framework. See the GitHub Privacy Statement.

The website loads nothing from other servers and sets no cookies. Legal basis: Art. 6 (1) (f) GDPR (legitimate interest in providing the website).

4. Demo

The demo at getstarchat.net/demo is the StarChat web client. The network ST-City is preselected, another one can be chosen under the advanced settings. When you connect, the chosen network receives your IP address and everything you enter there. For ST-City, the ST-City privacy policy applies.

Your choices (network, nickname, start channel) and settings are kept by your browser in the local storage of your device. They do not reach us. This storage is required for the function (§ 25 (2) no. 2 TDDDG).

5. Apps

Connection: Like the demo, the apps connect directly to the chosen network. We receive no data.

Stored data: Connections, settings, logins and drafts stay on your device. Passwords and login tokens are stored encrypted (Android: Android Keystore; desktop: the key store of the operating system) and are only sent to the network they were saved for.

Server list: The apps load the list of public networks from GitHub (raw.githubusercontent.com). GitHub receives your IP address, see section 3.

Desktop updates: The desktop app checks GitHub for new versions at start and regularly afterwards and downloads them from there. GitHub receives your IP address.

Error log: The desktop app logs program errors only on your device. You copy a report from the settings yourself and decide where to send it.

Images and videos in the chat: When someone shares a link to an image or a YouTube video, the app loads the preview directly from that server (for YouTube from Google), which receives your IP address. The YouTube player is only loaded when you tap the preview; then the Google Privacy Policy applies.

Microphone: The app only uses the microphone when you join a voice chat or call, or test the microphone in the settings. Voice chat is provided by the network.

6. Push notifications of the Android app

If you are logged in on a network that supports Web Push and allow notifications, the app signs up for push. It creates its own keys on your device and gets a device token from Firebase Cloud Messaging (FCM).

Push gateway: The app sends the FCM token to our push gateway push.getstarchat.net. The gateway checks with FCM that the token belongs to the StarChat app and answers with a push address that contains the token in encrypted form. The app hands this address and the public keys of your device to the IRC network. The network sends notifications to the gateway, which passes them on to FCM.

The gateway stores no tokens, no push addresses and no content, and logs no IP addresses. To limit abuse it keeps the IP address of a sign-up in memory for up to ten minutes. It runs on a rented server; the hosting provider processes the data on our behalf (Art. 28 GDPR).

Content: The IRC network encrypts sender and text of a notification with the keys of your device (RFC 8291). Only the app on your device decrypts it. Neither the gateway nor Google can read the content.

Firebase Cloud Messaging: Delivery is done by FCM of Google Ireland Ltd., Gordon House, Barrow Street, Dublin 4, Ireland. Data may be transferred to Google LLC in the USA. Google is certified under the EU-US Data Privacy Framework. We only use message delivery from Firebase, no analytics or advertising features. See the Firebase privacy information.

Legal basis is your consent (Art. 6 (1) (a) GDPR), given through the notification prompt of your device, where you can withdraw it at any time. If you remove the app, the token becomes invalid and the network drops the sign-up on its next attempt.
